# KP Showcase — Internal Tools

Case study + demo aplikasi custom untuk project Kerja Praktik.

- `index.html` — halaman case study (pintu masuk)
- `app/index.html` — aplikasi custom (demo interaktif)

Kode Lowcoder (versi yang di-deliver saat KP): https://github.com/Yombia/Project-KP-Yosia

## Deploy (Vercel)
1. Push folder ini ke sebuah repo GitHub.
2. Di Vercel: Add New → Project → import repo tersebut.
3. Framework Preset: **Other** (situs statis, tanpa build step).
4. Deploy. Case study terbuka di URL utama, demo di `/app`.
